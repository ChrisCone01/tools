# 图片裁剪工具

浏览器内批量裁剪工具，单文件 HTML，打开即用。

## 在线使用

**GitHub Pages（推荐）：** https://chriscone01.github.io/tools/image-cropper/

本地打开：`index.html` 直接拖进浏览器或右键用浏览器打开。

## 功能

- **自定义裁剪尺寸**：16~8000px 任意输入，预设 840×680 / 210×170 / 1920×1080 / 1080×1080
- **批量处理**：一次上传多张，逐张编辑
- **拖动定位**：拖空白处移动背景图，滚轮缩放
- **Logo 叠加**：15 个内置 logo 可选（唐宫、月麟、莫离、赴山海、逐玉），拖动改位置，滚轮缩放大小
- **上传自己的 logo**：顶部「Logo 素材」面板上传，自动裁掉四周空白边，存在浏览器本地，可随时删除
- **格式保留**：导出格式跟随上传格式（jpg 进 jpg 出），方便直接替换原图
- **编辑记录**：操作自动保存到浏览器本地，关闭页面后可还原，也可手动存多条记录对比

## 使用说明

1. **设置裁剪尺寸**：点预设按钮或手动输入宽高，点「应用」
2. **上传图片**：拖拽或点击上传区域
3. **调整构图**：
   - 拖动空白处移动背景图
   - 滚轮缩放背景图（框内滚动）
   - 点击 logo 缩略图添加，再次点击取消
   - 拖动 logo 改位置，在 logo 上滚动缩放 logo
4. **确定当前图片**：点「✓ 确定」，自动滚动到下一张
5. **下载**：全部编辑完后点「📥 下载全部图片」，打包为 zip

## 技术说明

- **单文件架构**：无构建步骤，`index.html` 包含全部代码
- **Logo 素材**：`logos.js`（1.2MB，15 个 base64 编码的 logo），由 `gen_logos.py` 从素材文件夹生成
- **自定义 logo**：上传的 logo 存在 IndexedDB 的 `logos` store（数据库 v2），和内置素材合并显示，内置的删不掉
- **本地存储**：编辑记录存在 IndexedDB（`imageCropper` 数据库），图片数据按内容去重，元数据单独存，关闭页面不丢失
- **预览优化**：小尺寸（如 210×170）放大显示便于操作，大尺寸（如 1920×1080）缩小显示省内存，导出始终是设定的完整尺寸

## 已知限制

- **格式降级**：浏览器只能导出 PNG / JPG / WebP，上传 GIF / BMP / TIFF / HEIC 会转成 PNG，界面会标橙色提示
- **源图分辨率**：如果源图小于裁剪框，必须放大才能填满，会发虚，界面会标红色警告
- **隐私模式**：无痕模式下 IndexedDB 不可用，编辑记录功能失效，其他功能正常
- **Logo 缓存**：`logos.js` 有 1.2MB 且浏览器缓存顽固，改代码后需 Ctrl+F5 硬刷新
- **空白边裁剪范围**：上传 logo 只裁四周的空白边，不去内部背景。白底 JPG 裁完仍是个白底方块（只是贴合了图形边界），要让白底透明得做抠色

## 开发

**生成 logo 素材：**
```bash
python gen_logos.py
```
从 `logos/` 目录读取 PNG，生成 `logos.js`（WebP 编码，quality 92，小于 PNG 时用 WebP，否则保留 PNG）。

**本地测试：**
直接用浏览器打开 `index.html`，IndexedDB 按域名隔离，`file://` 协议和 `https://chriscone01.github.io` 的记录互不干扰。
